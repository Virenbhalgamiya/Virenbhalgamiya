## 🔥 Featured Architecture & Research Projects

### 🔹 **[Enterprise Federated Anomaly Detection](https://github.com/Virenbhalgamiya/Federated-Anomaly-Detection)**
- Decentralized Deep Learning architecture built for High-Energy particle physics data. Uses a PyTorch Variational Autoencoder (VAE) to detect anomalies across remote nodes. Secures data via Differential Privacy (PyTorch Opacus) and stabilizes Non-IID variance via FedProx.
- **Tech:** PyTorch, Opacus, Federated Learning, Scikit-Learn

### 🔹 **[Adaptive Agentic RAG](https://github.com/Virenbhalgamiya/adaptive-agentic-rag)**
- An intelligent, self-correcting RAG system featuring a LangGraph state-machine that intrinsically routes questions to vector databases, web searches, or direct LLMs. It includes an active grading loop to detect hallucinations and self-correct queries.
- **Tech:** LangGraph, ChromaDB, FastAPI, DeepSeek V3

### 🔹 **[Safe LLM-Based Task Automation System](https://github.com/Virenbhalgamiya/Safe-LLM-Based-Task-Automation-System)**
- A research-oriented framework decoupling LLM intelligence from deterministic execution. Uses GPT-4 strictly as an intent parser while a rigid mathematical Policy Validator deterministically checks security parameters before any execution occurs.
- **Tech:** Python, LLMs, Deterministic Policy Engines

### 🔹 **[High-Performance Order Matching Engine](https://github.com/Virenbhalgamiya/High-Performance-Order-Matching-Engine)**
- An ultra-low latency C++20 limit order book trading system with automated price-time priority. Implements minimal dynamic allocation in the hot path via ObjectPool memory reuse, lock-protected ring queues, and a multi-threaded TCP order gateway.
- **Tech:** C++20, Multithreading, Low-Latency Systems, CMake
